# API Reference

- [github.com/stretchr/testify](https://testify-docs.github.io/reference/package-root.md): Module testify is a set of packages that provide many tools for testifying that your code will behave as you intend.
- [github.com/stretchr/testify/assert](https://testify-docs.github.io/reference/pkg-assert.md): Package assert provides a set of comprehensive testing tools for use with the normal Go testing system.
- [github.com/stretchr/testify/http](https://testify-docs.github.io/reference/pkg-http.md): Deprecated: Use net/http/httptest instead.
- [github.com/stretchr/testify/mock](https://testify-docs.github.io/reference/pkg-mock.md): Package mock provides a system by which it is possible to mock your objects and verify calls are happening as expected.
- [github.com/stretchr/testify/require](https://testify-docs.github.io/reference/pkg-require.md): Package require implements the same assertions as the assert package but stops test execution when a test fails.
- [github.com/stretchr/testify/suite](https://testify-docs.github.io/reference/pkg-suite.md): Package suite contains logic for creating testing suite structs and running the methods on those structs as tests.
